# 心境（mood）

让糯糯有自己的心情、精力和对你的信任：随对话变化，隔一段时间自然回落；按你当下的状态调整说话方式。插件本身不调用模型。

## 怎么工作

1. 主 Agent 回答你的新消息前，插件根据你这条消息的字面先判断一下你的状态（着急干活、在倾诉、两者都有），再加上糯糯现在的心境，组成一小段 `<mood>` 附在输入后面（约 200 字）。它放在输入里而不是系统提示词里，所以不会打破提示词缓存。
2. 主 Agent 回复你时，在同一步里顺手调用 `mood_sync`，报告你这轮的情绪、强度、对它的态度、对上一轮回答的反馈。插件据此更新心境。漏报了就保持原样，不影响回复。
3. 心情和精力的半衰期是 6 小时；信任变化很慢，不会自己回落。

| 你这轮的状态 | 说话方式 |
| --- | --- |
| 着急又在干活 | 先一句话说中卡住的地方，接着直接给下一步 |
| 主要在倾诉 | 先回应感受，不急着列建议 |
| 要把事办成 | 直接给结论和步骤，不寒暄 |
| 平常、心情好且信任高 | 可以轻松一点、偶尔打趣 |
| 其他 | 平稳、真诚、平等 |

始终不说客服套话；信任 ≥ 60 时，觉得你想错了会直接、友善地指出。

**心境只改变语气，不会降低帮忙的程度。** 你语气冲，它心情会差一点、信任略降，但不会因此变冷淡、拒绝道歉或少给建议。

## 不做什么

- 不写记忆。关于你的事实仍由糯糯自己的记忆系统整理（有信任级别和待确认队列）。
- 没有单独的网页面板。状态存在插件的 `state` 里（`mood` 键，含最近 50 轮的变化），以后可以在「它是谁」里展示。

## 安装

在「设置 → 插件 → 安装插件」里填 `https://github.com/cyDione/nuonuo/tree/main/examples/plugins/mood`，然后启用。想重置，就跟糯糯说「把心境重置一下」（`mood_reset`）。
