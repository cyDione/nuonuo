# M6：Muse 式交互 + Grok Bot 式记忆（2026-11-05）

依据：[How we designed Muse](https://muse.ai/blog/how-we-designed-muse)（交互）与 [个人助手 Bot 架构](https://bot-pzt4.pages.grok.bot/)（薄控制面、重执行面、记忆旁路）。多 agent 群聊、目标与创意暂不做。

## 1. 安全：外部事件不能直接写记忆

只有你在**对话渠道**里的原话（网页、定时任务、你自己的 Telegram）可以直接写进记忆。信任级别由代码判断，不由模型判断：

- **主 Agent**：每批事件都会判断一次。只有这批全部是你在对话渠道里说的话，才能直接写入；GitHub 评论、邮件，即使是你自己发的，也只能进"等你确认"。
- **Worker**：它的工作必须来自你，而且在处理过程中没有读到过别人的消息（读到之后这次执行就被标记），才能直接写入；静默工作一律进"等你确认"。
- **自动整理**：只整理有你本人发言的对话。外部线程的镜像对话不会被整理。

## 2. 记忆系统（Grok Bot 的"记忆面"）

| | 做法 |
|---|---|
| 存储 | `memories` 表：内容、类别、项目、信任级别、置信度、来源消息、生效时间、到期时间、被哪条取代；`memory/MEMORY.md` 是只读副本。旧版的 markdown 记忆在首次启动时自动导入 |
| 类别 | 关于你（长期）、项目（只在该项目里用）、近期（默认 30 天到期）、经验 |
| 写入规则 | 置信度 ≥ 0.8 直接写；0.5–0.8 进"等你确认"；更低的不保存。来自外部的一律进"等你确认"。你确认时可以先改文字 |
| 后台整理（旁路） | 对话安静 2 分钟后：过滤层模型先判断值不值得记（记 / 待定 / 不记），摘要层模型再提炼 1–3 条，附上来源消息，并可以标出它要替换的旧记忆。判断为"待定"的，置信度最高只给 0.79，也就是一定先等你确认。这一切都不影响回复的速度 |
| 召回 | 主 Agent 的提示词里只放"关于你"的摘要；其余记忆按每次的输入检索，选出最相关的几条附在输入后面。检索是关键词加向量（配置了向量层时），当前项目的记忆优先 |
| 按项目绑定 | 每个侧聊、每个 GitHub 仓库都是一个项目。在项目里记下的项目记忆归属这个项目，由代码决定，不看模型起的名字 |
| 维护 | 每天整理一次：清理到期的近期记忆，合并几乎重复的条目（保留较新的）。设置页里也可以手动整理 |

## 3. Muse 式主对话

- **主对话**：打开应用就是它，像和一个人一直聊下去。它主动告诉你的事、定时任务的结果都发在这里（`message_owner`）。主对话里没有"把消息直接交给正在做的那件事"的捷径，始终由主 Agent 维持上下文连贯。
- **侧聊**：单独聊一个话题或项目，它会记住这个侧聊里定下的约定。
- **外部**：GitHub、Telegram 等线程的镜像，单独列在一组。
- **个性**：名字、头像、颜色、性格，都会写进主 Agent 的提示词；桌面通知也用这个名字。
- **消息气泡与头像**：连续几条消息只在第一条显示头像。定时任务触发时，只显示一行很淡的分隔线。
- **头像下的状态**："正在做：…"、"1 件事等你"。点头像打开活动面板，里面有需要你的事、正在做的、你允许过的、接下来、主动留意到的。

## 4. 批准与成果

- **批准卡片**："同意这一次"、"这件事里都同意"、"不同意"。选"这件事里都同意"后，这件事里同类的操作不再问你；这件事做完就失效，可以在活动面板撤回。不可撤销的操作每次都问。
- **成果直接预览**：markdown 渲染、CSV 显示成表格、图片和 PDF 直接看；HTML 页面在隔离的沙箱里可以交互，没有同源权限，碰不到应用本身。Worker 被引导在合适时交付单文件 HTML（行程、追踪表、小看板）。

## 6. 其他

- 流式响应在中途断掉（网关返回 200 但解析失败、连接重置）时，这一步会自动重试，最多两次。实测中遇到过一次，原来会让整件事直接失败。
- 实测（所有层都用 V4.1 Flash）：
  - 主 Agent 直接记下"小王，在杭州做后端开发"；后台整理提炼出"回答尽量简洁"（把握 95%）。
  - 健身计划交付成可以勾选的 HTML 页面，在对话里直接预览。
  - 批准卡片和活动面板正常。
  - 侧聊里的约定归到了该侧聊名下。
- 尚未用真实模型验证的部分（由单元测试覆盖）：
  - "这件事里都同意"在第二次同类操作时自动放行。实测中 Worker 把两条命令合成了一条，所以只批准了一次。
  - 外部来源的记忆进入"等你确认"。
